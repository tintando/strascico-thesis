So what do the layers show? Start with edits. Telegram stamps an edit date on every edited message, and by that flag, one message in three has been edited. That is misleading. Of the edits we caught and diffed, ninety-three percent left the text byte for byte identical: it might be added media, link previews resolving, formatting. The flag over-counts real rewriting about ten times, and only the visit-to-visit diff, which holds both versions, can tell the difference.
